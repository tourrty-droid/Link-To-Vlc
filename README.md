# 📺 Link to VLC (Live Stream Player & M3U8 Generator)

Простой, легкий и стильный веб-инструмент для преобразования прямых трансляций YouTube в чистые встроенные плееры и удобные **M3U8 HLS-потоки** для воспроизведения в **VLC Media Player**, IPTV-плеерах или OBS Studio.

Проект специально оптимизирован для быстрой публикации на **GitHub Pages** за считанные минуты.

---

## ✨ Особенности

- 🎯 **Универсальная поддержка YouTube**: Принимает любые стандартные ссылки на трансляции (`watch?v=`, `youtu.be`, `embed/`).
- 🎬 **Чистый плеер**: Генерирует ссылку на embed-плеер без лишних блоков, чатов и интерфейса YouTube.
- 📡 **Совместимость с VLC / IPTV**: Автоматически формирует M3U8 HLS-поток через публичные API, который напрямую запускается в VLC Media Player.
- 📱 **Адаптивный интерфейс**: Удобно пользоваться как с компьютера, так и со смартфона или планшета.
- ⚡ **Без бэкенда**: Работает полностью в браузере (Pure HTML5 + JavaScript).

## 💡 Как использовать

1. Скопируйте ссылку на прямой эфир YouTube.
2. Вставьте её в поисковую строку на созданном сайте и нажмите **Сгенерировать**.
3. **Получите нужные ссылки:**
   - **Embed URL** — для вставки в веб-страницы или отдельного просмотра.
   - **M3U8 Stream URL** — для открытия в медиаплеерах.

### 🎥 Запуск потока в VLC Media Player:
1. Скопируйте полученную ссылку на **M3U8 Поток**.
2. Откройте **VLC Media Player**.
3. Нажмите `Ctrl + N` (или выберите в меню: *Медиа $\rightarrow$ Открыть URL*).
4. Вставьте ссылку в поле ввода и нажмите **«Воспроизвести»**.
